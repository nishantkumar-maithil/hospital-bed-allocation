# Hospital Bed Allocation System

Desktop app (Python + Tkinter) to manage hospital bed allocation — implements DAA concepts (Linear Search, Greedy Allocation).

## Features
- Patient registration & ward assignment
- Bed allocation / discharge
- Ward-wise availability dashboard
- Uses MySQL for persistence (config via .env)

## Install (dev)
1. `python -m venv venv`
2. `source venv/bin/activate` (Linux/Mac) or `venv\Scripts\activate` (Windows)
3. `pip install -r requirements.txt`
4. `python src/main.py`

## Project structure
- `src/` — source code
- `docs/` — screenshots & report
